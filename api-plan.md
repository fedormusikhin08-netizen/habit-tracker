# План REST API

## Endpoints

| Метод  | Путь          | Описание              |
|--------|---------------|-----------------------|
| GET    | /habits       | список привычек       |
| POST   | /habits       | создать привычку      |
| GET    | /habits/{id}  | получить одну привычку |
| PUT    | /habits/{id}  | обновить привычку     |
| DELETE | /habits/{id}  | удалить привычку      |

## Формат данных

Привычка описывается полями: `id`, `name`, `period`, `created_at`.
