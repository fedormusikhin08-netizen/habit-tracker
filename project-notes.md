# Рабочие заметки проекта

## Идея

Трекер привычек: пользователь добавляет привычки, ежедневно отмечает
их выполнение и следит за своей серией без срывов.

## Ключевая функциональность

- добавление и удаление привычек
- ежедневная отметка выполнения
- календарь отметок за месяц
- серия дней подряд (streak)

## Открытые вопросы

- Хранилище: SQLite (решено).
- Как учитывать часовой пояс пользователя?
- Нужны ли напоминания о привычках?

## Выбор технологий

- Язык: C# (.NET 8)
- Фреймворк: ASP.NET Core Web API
- ORM: Entity Framework Core
- Хранение: SQLite
