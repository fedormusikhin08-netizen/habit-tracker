# Трекер привычек

Учебный проект для отслеживания полезных привычек.

## Описание

Пользователь создаёт привычки (например, «пить воду» или «читать 30 минут»),
отмечает выполнение каждый день и видит статистику и текущую серию (streak).

## Технологии

- Язык: C# (.NET 8)
- Фреймворк: ASP.NET Core Web API
- ORM: Entity Framework Core
- Хранение: SQLite
- Фронтенд: планируется позже
