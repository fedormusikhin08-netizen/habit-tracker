# Трекер привычек

Учебный проект для отслеживания полезных привычек.

## Описание

Пользователь создаёт привычки (например, «пить воду» или «читать 30 минут»),
отмечает выполнение каждый день и видит статистику и текущую серию (streak).

## Структура проекта

- `README.md` — описание проекта (этот файл)
- `project-notes.md` — рабочие заметки команды
- `api-plan.md` — план REST API

## Статус

Проект в стадии планирования. Зафиксирована тема и первоначальная структура.
